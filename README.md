# ATS CV Builder

Upload an existing CV (PDF, Word or text). The page reads it and rebuilds it as a simple, ATS-friendly CV, shows what was added or removed, and suggests what to improve.

## Run it
Open `index.html` in a browser. No install needed.

## Host it free
GitHub Pages: Settings > Pages > Deploy from branch > `main` and `/ (root)`.

## Notes
- The ₹19 download step is a demo. Real payment needs a backend (for example Razorpay with a serverless function).
- Files are read in the browser and are not uploaded anywhere.
